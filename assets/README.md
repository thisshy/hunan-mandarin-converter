# 界面素材

- `design-system.css`：两端共用颜色、字体、焦点样式和基础规则。文化标题沿用宋体字形，表单和正文使用系统无衬线字体。
- `theme.js`：跟随系统外观，支持手动切换与本地记忆；提供复制结果和状态提示。
- `icons.svg`：Tabler Icons 3.34.1 的 language、compass、book-2、chart-bar，保持原始路径，合并为 SVG symbol；MIT 许可见 `TABLER-LICENSE.txt`。
- `xiang-river.png`：内置 imagegen 生成的湘江沿岸主题插画。它是文化主题配图，不是实景照片或精确地理图。

设计取向：在原有湘言通品牌上调整排版与层级；视觉变化 5/10、动效 2/10、信息密度 5/10。重点是方言工具可用性，主色为青绿，弱化装饰渐变与卡片嵌套。

## 插画生成提示词

Restrained palette: mist grey #f3f6f3, deep river teal #216358, soft jade, ink charcoal, just a tiny warm burnt orange detail. Richly textured yet clean elegant shapes, airy layered composition, river sweeping gently from foreground left to background center. Scenic not a precise geographic map, no invented landmark monument. Wide open quiet sky in top quarter. Detailed enough to feel like a beautiful book cover; contemporary editorial art not generic clip art or photorealistic. NO text, NO letters, NO logos, NO labels, NO borders, NO interface elements. Will appear in a horizontal web hero and cropped app banner. Save output as project illustration.
